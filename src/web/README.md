# Thiết kế giao diện web

Giao diện web Python sẽ được cài ở các tuần tiếp theo và gọi cùng `src/core` với terminal. Bản tuần 1 chỉ chốt luồng sử dụng:

1. Hiện lưới 4×4, mỗi ô nhận số 1–4 hoặc để trống.
2. Nút nạp ví dụ 1, nạp ví dụ 2 và xóa bảng.
3. Nút kiểm tra đầu vào; khi bộ giải hoàn thành sẽ có nút giải và xem bước quay lui.
4. Phân biệt đề không hợp lệ, đề hợp lệ vô nghiệm và tìm được nghiệm.
5. Ứng dụng triển khai phải dùng chính bộ lõi đã kiểm thử, không viết thuật toán thứ hai.

Chưa có ứng dụng chạy hoặc URL deploy ở tuần 1.
