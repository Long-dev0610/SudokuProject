# Ảnh kết quả

Tuần 2 đã có đủ A01–A11 do sinh viên chạy hai ví dụ DT041, hai ca tự thiết kế,
ba ca biên, kiểm tra đầu vào lỗi, bộ unittest từ ZIP, clone commit C và mở
permalink GitHub của thuật toán chính. Ảnh lấy từ lần chạy và thao tác thật
trên máy sinh viên, không dùng ảnh mẫu BFS làm minh chứng cho đề Sudoku.

có 55 lần thử, 18 lần đặt, 7 lần hoàn tác và một nghiệm hợp lệ. A01–A11
thuộc commit C2; B01 thuộc mã/test/input C3 và được giữ riêng để tránh nhầm SHA.
